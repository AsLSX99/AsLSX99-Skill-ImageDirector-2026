# 画面圣经模板（7 模块）

> 语义层填写，模型无关。填完按 08 方言表翻译投放。

```markdown
## 画面圣经 v1
### 0. 目标
- 投放渠道/用途：【如：小红书封面】→ 决定画幅
- 目标模型：【GPT Image / Midjourney / SD-FLUX / 即梦类 / 通用】→ 决定方言
- 生成 or 改图：【改图则必填不变量范围】

### 1. 主体设定
- 【年龄】岁成年【地域/人种】【性别】，【脸型】，【五官特征】，
  【发型：长度/颜色/卷直】，穿【服装：款式+剪裁+材质+颜色】。
- 必须保留的特征：【痣/配饰/妆容锚点】
- 参考素材：@图1【锁定职责】｜@图2【锁定职责】

### 2. 场景与动作
- 【时间/氛围】的【具体地点+位置】，【人物】正在【动作过程】，
  【身体朝向/重心】，【目光落点】，【与环境的互动】。

### 3. 视觉风格
- 【风格大类：拟真摄影/风格化/商业】：【具体风格】，
  【标志性特征 2–3 个】，风格强度【轻微/标准/强烈】。

### 4. 构图与镜头
- 【画幅】，【机位】【景别】构图，主体位于【方位】，
  【留白百分比 + 用途】。

### 5. 光影与色彩
- 光：【质地】的【光源】从【方向】照入，【亮部】，【阴影层次】。
- 色：【底色2–3个】为背景，服装保持独立色彩，肤色自然通透。
- 禁区色：【颜色】

### 6. 材质与细节（挑 3–4 个关键位）
- 皮肤：【真实毛孔与自然纹理 / 按风格适配】
- 服装：【材质的光泽/肌理/褶皱】
- 头发：【细密发丝/蓬松感】
- 环境：【反射/阴影/纹理 选 1–2】

### 7. 负面约束
- 通用：避免五官变形、手指异常、肢体不协调、人物悬浮、
  皮肤塑料感、画面灰蒙、整图偏色。
- 定制（挑 2–3）：【避免换脸/避免对立风格/避免出框/避免禁区色】
- 改图不变量（如适用）：只修改【指定内容】，其余
  【五官/服装/构图/光线】保持不变。
```

## 单句速成版（赶时间用，仍覆盖 7 模块）

```
{主体四要素}，{场景+动作+目光}，{风格+特征}，{画幅+景别+机位+布局}，
{光的方向与层次}，{底色+独立色+肤色}，{1–2 个细节位}，
避免{3 条最要命的负面}。
```
