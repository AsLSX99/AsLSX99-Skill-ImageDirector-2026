# 完整示例：咖啡馆人像（一份圣经，三种方言）

> 同一份画面圣经翻译成 GPT Image / Midjourney / 通用兜底三种投放提示词，展示双层架构的实际形态。

## 画面圣经（语义层）

```markdown
### 0. 目标
- 用途：小红书人像封面 → 画幅 9:16
- 目标模型：三种都出（见下方方言）
- 生成（非改图）

### 1. 主体设定
一位 25 岁的成年东方女性，精致鹅蛋脸，清亮杏眼，黑色微卷长发，
穿奶油白色修身连衣裙。必须保留：左眼角小痣、耳垂珍珠耳钉、自然唇色。

### 2. 场景与动作
午后咖啡馆的窗边，她一只手端起咖啡杯，身体自然侧向镜头，
目光落在窗外，阳光在杯沿投下一小片高光。

### 3. 视觉风格
电影摄影风格：浅景深，35mm 胶片颗粒，青橙色调分级；风格强度标准，
保留真实五官与皮肤纹理。

### 4. 构图与镜头
9:16 竖版，平视半身构图，人物位于画面右侧，左侧保留 40% 环境留白。

### 5. 光影与色彩
柔和的午后自然光从左侧窗户照入，脸部明亮，阴影具有自然层次；
奶油白与浅木色为背景，服装保持独立色彩，肤色自然通透。
禁区色：高饱和正红。

### 6. 材质与细节
皮肤真实毛孔与自然纹理；连衣裙的丝质光泽与下摆褶皱；
黑色微卷发的细密发丝与蓬松感；窗玻璃的环境反射。

### 7. 负面约束
避免五官变形、手指异常、肢体不协调、人物悬浮、皮肤塑料感、
画面灰蒙、整图偏色；避免时尚杂志硬光棚拍感；避免肤色发灰。
```
