# 04 构图与镜头：决定图片好不好看

> 产出：四要素构图句（画幅/景别/机位/布局）。这是最容易被忽略的一步——构图不是装饰，它直接决定画面的视觉重心。

## 四要素

| 要素 | 选项 | 说明 |
|------|------|------|
| 画幅 | 9:16 / 4:5 / 1:1 / 16:9 / 3:2 | 竖版人像、方图社交媒体、横版叙事 |
| 景别 | 特写 / 半身 / 七分身 / 全身 | 决定主体占画面比例与细节可见度 |
| 机位 | 平视 / 俯拍 / 仰拍 / 鸟瞰 / 贴地 | 决定权力关系与透视（仰拍高大、俯拍柔弱） |
| 布局 | 居中 / 三分法 / 对称 / 大面积留白 / 前景遮挡 | 决定视觉重心与呼吸感 |

## 写法句式

```
{画幅}竖/横版，{机位}{景别}构图，{主体位于画面哪}，
{留白/陪体安排}（{百分比}环境留白）。
```

示例：

> 9:16 竖版，平视半身构图，人物位于画面右侧，左侧保留 40% 环境留白。

## 关键纪律

1. **四件事至少写满 4 件**——"构图精美"四个字等于没写。
2. **布局给百分比或明确方位**："人物位于画面右侧，左侧 40% 留白"比"适当留白"可控一个量级。
3. **机位服务叙事**：平视=平等自然；俯拍=被动/可爱；仰拍=力量/压迫。与 02 的故事感对齐。
4. **留白是功能位**：留白处将来要放文字（海报/封面）就显式写"左侧留白用于排版文字"。
5. **画幅与投放渠道绑定**：手机封面 9:16、小红书 3:4 或 1:1、公众号头图 16:9、打印 3:2——先定渠道再定画幅。
6. **与方言层的接口**：Midjourney 用 `--ar 9:16` 参数表达画幅，SD 用外接尺寸设置——**画幅在方言层可能不进提示词正文**，翻译时注意（见 08）。

## 常见错误

| 错误 | 症状 | 修复 |
|------|------|------|
| 不写构图 | 主体永远居中大头 | 四要素写满 |
| 画幅与渠道不符 | 发布时裁切毁构图 | 先定投放渠道 |
| 俯仰拍乱用 | 情绪与机位打架 | 机位对齐叙事意图 |
| 留白不给量 | 文字没地方放 | 百分比+用途声明 |
| 正文写了画幅但方言层丢掉 | MJ 里画幅不生效 | 按 08 翻译成对应参数 |
