# 07 负面约束：告诉 AI 哪些不能出错

> 产出：负面清单（生成）+ 不变量声明（改图）。除了告诉 AI 要什么，还要明确哪些东西不能出现——这是减少反复抽卡的重要手段。

## 一、生成图负面清单（通用 7 条）

```
避免五官变形、手指异常、肢体不协调、人物悬浮、皮肤塑料感、画面灰蒙、整图偏色。
```

| 约束 | 拦什么 | 高发场景 |
|------|--------|---------|
| 五官变形 | 眼歪嘴斜、脸崩 | 特写、强风格化 |
| 手指异常 | 多指/粘连/畸形 | 手部入镜（重灾区） |
| 肢体不协调 | 关节反向、比例崩 | 复杂动作、坐姿 |
| 人物悬浮 | 脚不接地、无投影 | 全身、动态 |
| 皮肤塑料感 | 磨皮过度 | 美颜类风格 |
| 画面灰蒙 | 对比度丢失、发灰 | 逆光、多重风格叠加 |
| 整图偏色 | 单色罩染、肤色异常 | 强色调描述 |

## 二、按模块追加的定制负面项

从失守概率最高的模块挑 2–3 条，不全塞（负面词过多会稀释正向描述的注意力）：

- 01 主体失守 → `避免人物换脸、特征丢失`
- 03 风格串味 → `避免出现 {对立风格特征}`
- 04 构图失守 → `避免主体出框、避免构图裁切`
- 05 色彩失守 → `避免 {禁区色}、避免肤色发灰`

## 三、改图/局部重绘的不变量声明（必加）

修改现有图片时，除了"改什么"，必须声明"不许动什么"：

```
只修改指定内容，其余人物五官、服装、构图和光线保持不变。
```

进阶版（按需加项）：

```
只修改 {指定内容}，其余 {人物五官/服装/发型/构图/光线/色彩/背景/画幅}
保持与原图完全一致，不重新生成未指定区域。
```

**没有不变量声明的改图 = 让模型重开一锅**，改了头发脸也变了——这是改图翻车的第一原因。

## 四、方言层位置提示

负面约束在不同模型的落点不同（详见 08）：

- 有独立负面框的（SD/FLUX/部分国产）→ 填进负面框
- 无负面框的（GPT Image/MJ 部分场景）→ 转写成正向祈使句："画面保持干净，无手指畸形"，或用 MJ 的 `--no` 参数
- 对话式生图 → 直接作为"避免出现…"一段放在提示词末尾

## 常见错误

| 错误 | 症状 | 修复 |
|------|------|------|
| 只写要什么不写不要什么 | 抽卡次数翻倍 | 通用 7 条起步 |
| 负面项堆太多 | 正向描述被稀释、画面保守 | 挑 2–3 条定制项 |
| 改图无不变量声明 | 改一处崩全图 | 必加"只修改指定内容…" |
| 负面词放错位置（方言） | 约束不生效 | 按 08 落点翻译 |
