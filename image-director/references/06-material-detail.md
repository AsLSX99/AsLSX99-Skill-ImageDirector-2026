# 06 材质与细节：决定图片耐不耐看

> 产出：细节声明清单（皮肤/服装/头发/环境各一条）。真正拉开图片质感差距的往往是细节——告诉 AI 具体要表现什么细节，比堆砌画质形容词更有意义。

## 四个细节位

| 位 | 不写时的默认 | 写了之后 |
|----|-------------|---------|
| 皮肤 | 塑料感、磨皮过度 | 真实毛孔、自然纹理 |
| 服装 | 平面感、像贴图 | 丝绸光泽、针织肌理、棉麻褶皱 |
| 头发 | 整块头套感 | 细密发丝、自然蓬松、碎发 |
| 环境 | CG 空间感 | 玻璃反射、物体阴影、灰尘颗粒 |

## 写法句式

```
细节表现：{皮肤：真实毛孔与自然纹理}；{服装：{材质}的{光泽/肌理/褶皱}}；
{头发：细密发丝与蓬松感}；{环境：{反射/阴影/纹理中的 1–2 项}}。
```

示例：

> 细节表现：皮肤真实毛孔与自然纹理；奶油白连衣裙的丝质光泽与下摆褶皱；黑色微卷发的细密发丝与蓬松感；窗玻璃的环境反射与桌面物体阴影。

## 关键纪律

1. **与风格联动**：3D CG 风格的皮肤细节是"次表面散射的通透感"而非毛孔——细节声明按风格适配，别把写实细节硬塞给风格化模型。
2. **写具体不写画质词**："4K、超高清、 masterpiece、best quality"这类词的信息量趋近于零（方言层里部分模型仍保留作触发词，但**质感靠细节位，不靠画质形容词**）。
3. **细节位是防"假"的最后防线**：前五模块决定"画什么"，本模块决定"摸起来真不真"。
4. **取舍**：一图挑 3–4 个最影响质感的细节位写透，全写会稀释注意力（与视频工作流"关键要求说清楚>篇幅长"同理）。

## 常见错误

| 错误 | 症状 | 修复 |
|------|------|------|
| 堆画质形容词 | 数值高但假 | 换成四个细节位具体描述 |
| 细节与风格冲突 | 写实毛孔出现在动漫里 | 细节按风格适配 |
| 每个位都写 | 注意力稀释 | 挑 3–4 个关键位 |
| 漏环境细节 | 人真景假 | 环境补反射/阴影一项 |
