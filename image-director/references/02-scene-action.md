# 02 场景与动作：决定画面有没有故事感

> 产出：环境描述 + 动作描述。很多 AI 图片一眼假，就是因为人物只会站着看镜头。

## 核心判断

**有动作的画面比摆拍更有生活感。** 站立直视镜头 = 证件照；端杯、侧身、目光落向窗外 = 一张有故事的照片。动作还顺带解决了另一个问题——手不知道往哪放的僵硬感。

## 三要素

| 要素 | 回答 | 示例 |
|------|------|------|
| 在哪 | 具体环境 + 空间关系 | 午后咖啡馆的窗边 |
| 做什么 | 正在进行的、有过程感的动作 | 一只手端起咖啡杯 |
| 与环境互动 | 身体/目光/物体与环境的关系 | 身体自然侧向镜头，目光落在窗外 |

## 写法句式

```
{时间/氛围} 的 {具体地点}，{人物} 正在 {动作（有先后或过程）}，
{身体朝向/重心}，{目光落点}，{与环境的互动细节}。
```

示例：

> 午后咖啡馆的窗边，她一只手端起咖啡杯，身体自然侧向镜头，目光落在窗外。

## 动作设计规则

1. **写过程不写姿态**："端起咖啡杯"（过程）优于"拿着咖啡杯"（静态）优于"手放杯子旁边"（僵）。
2. **目光必须给落点**：看窗外、看杯中、看对面空座位——目光有落点，画面就有画外空间，故事感由此而来。
3. **给身体一个朝向和重心**：侧向镜头、重心在左腿、微微前倾——避免正面直立的"假人感"。
4. **互动要真实物理**：手推开门、风吹起发丝、脚踩进水洼。互动是"环境对人产生了影响"，不只是人摆了姿势。
5. **一图一个主要动作**：叠加太多动作（边跑边笑边打电话）模型会糊。

## 场景的颗粒度

- 合格："午后咖啡馆的窗边"（时间+地点+位置）
- 更好：补光源方向与环境元素——"午后咖啡馆靠窗座位，光从左侧玻璃照入，桌上有半块提拉米苏"（与 05 光影模块衔接）
- 不合格："一个漂亮的地方"（无法作画）

## 常见错误

| 错误 | 症状 | 修复 |
|------|------|------|
| 人物站直看镜头 | 证件照感、一眼假 | 给动作+目光落点+身体朝向 |
| 只写地点不写互动 | 人像贴背景板 | 补"与环境互动"一句 |
| 动作太多太杂 | 肢体扭曲 | 一个主要动作 |
| 场景过虚 | 背景随机 | 时间+地点+位置+光源方向 |
| 手部无事可做 | 手指异常高发区 | 让手参与互动（端/扶/翻/撩发） |
