# 05 光影与色彩：决定图片有没有质感

> 产出：光描述 + 色彩描述。为什么有些 AI 图片看起来很贵，有些像廉价滤镜？很大一部分区别就在这里。

## 光影：写方向、质地、层次

| 要素 | 写什么 | 示例 |
|------|--------|------|
| 方向 | 从哪来 | 从左侧窗户照入 |
| 质地 | 柔和/硬朗/直射/漫射 | 柔和的午后自然光 |
| 层次 | 亮部与暗部的关系 | 脸部明亮，阴影具有自然层次 |

写法句式：

```
{质地}的 {光源} 从 {方向} 照入，{亮部在哪}，{阴影有自然层次/轮廓光勾边}。
```

示例：

> 柔和的午后自然光从左侧窗户照入，脸部明亮，阴影具有自然层次。

光的常用配方（与 03 风格联动）：

| 风格 | 光配方 |
|------|--------|
| CCD 写真 | 正面直闪，主体明亮，背景压暗，高光轻微溢出 |
| 电影摄影 | 侧光/逆光，明暗比高，阴影偏青 |
| 时尚杂志 | 硬光棚拍，轮廓分明，或柔光箱大面积柔光 |
| 产品摄影 | 无影柔光，材质高光精准 |

## 色彩：写底色、独立色、肤色

写法句式：

```
{底色/环境色}为 {色}，{主体服装}保持独立色彩，肤色自然通透。
```

示例：

> 奶油白与浅木色为背景，服装保持独立色彩，肤色自然通透。

### 三条色彩纪律

1. **不要让整张图片被同一种颜色覆盖**——单色罩染是"廉价滤镜感"的直接来源。声明"服装保持独立色彩、肤色自然"。
2. **给 2–3 个具体色**（可用 HEX 或常见色名）：环境底色 + 主体色 + 点缀色，与视频工作流的色卡逻辑一致。
3. **肤色永远独立**：肤色通透、真实血色是"贵"的关键锚点，任何风格化都不该把肤色一起染了（写进负面约束：避免整图偏色、皮肤塑料感）。

## 常见错误

| 错误 | 症状 | 修复 |
|------|------|------|
| 不写光 | 平光、无立体感 | 方向+质地+层次三件套 |
| 光与风格矛盾 | 自然光描述出硬棚拍 | 按 03 的配方表校准 |
| 整团单色罩染 | 廉价滤镜感 | 底色+独立色+肤色三声明 |
| 色彩只写"温暖色调" | 每张色温不同 | 给 2–3 个具体色 |
| 肤色被染 | 脸发青/发黄 | 肤色独立+负面约束 |
