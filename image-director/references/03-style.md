# 03 视觉风格：决定图片最终长什么样

> 产出：一个明确的风格标签（+风格参数）。同一个人物、同一个场景，换一种风格，出来的图片可能完全不同。

## 核心判断

**不要只写"高级感"——你得明确告诉 AI，到底是哪一种高级感。** 风格是全图的渲染管线：它决定光影怎么打、颗粒有没有、皮肤怎么处理、颜色怎么压。风格含糊 = 把渲染控制权交给模型。

## 风格速查表（三选一后还要给亚型）

| 大类 | 风格 | 关键词特征 | 适用 |
|------|------|-----------|------|
| 拟真摄影 | iPhone 随手拍 | 真实、自然、轻微过曝、无修饰感 | 日常、vlog 封面 |
| 拟真摄影 | CCD 写真 | 直闪、轻颗粒、高光溢出、复古色彩 | 青春、街拍 |
| 拟真摄影 | 电影摄影 | 光影叙事、浅景深、色调分级 | 故事感、剧照 |
| 拟真摄影 | 时尚杂志 | 高级、精致、硬光/棚拍、强造型 | 大片、封面 |
| 风格化 | 3D CG | 立体、梦幻、次表面散射、柔光 | 梦幻、IP 形象 |
| 风格化 | 日系动漫 | 赛璐璐、粗描边、高饱和 | 二次元 |
| 风格化 | 插画/绘本 | 手绘笔触、纸纹、有限色板 | 文艺、儿童 |
| 商业 | 产品摄影 | 纯净背景、精准布光、材质特写 | 电商、详情页 |

## 写法句式

```
{风格大类}：{具体风格}，{该风格的 2–3 个标志性特征}。
（可选）{风格强度}：轻微/标准/强烈——保留人物真实特征还是允许风格化改写。
```

示例：

> 电影摄影风格，浅景深，35mm 胶片颗粒，青橙色调分级。

## 关键纪律

1. **风格一个，不混写**："时尚杂志感的动漫风"会让两个管线打架。需要混用时（真人+贴纸元素），显式分区。
2. **风格决定后续模块**：选 CCD 就要有直闪和颗粒（05/06 模块跟着变）；选产品摄影就纯净背景（02 场景跟着变）。**风格先定，其余模块随之校准**。
3. **给风格强度**：人物一致性要求高时写"轻微风格化，保留真实五官与皮肤纹理"；创意图可以"强烈风格化"。
4. **防串味**：负面约束里加"不出现 {对立风格特征}"（如电影摄影图加"避免时尚杂志硬光棚拍感"）。

## 常见错误

| 错误 | 症状 | 修复 |
|------|------|------|
| 只写"高级感/氛围感" | 每张风格都不一样 | 从速查表选具体风格+特征 |
| 一图多风格 | 管线打架、四不像 | 一个主风格，混用需分区声明 |
| 风格与光影模块矛盾 | 说好自然光出棚拍感 | 风格定了之后校准 05 |
| 无风格强度 | 人物被风格化改脸 | 加"保留真实五官"声明 |
