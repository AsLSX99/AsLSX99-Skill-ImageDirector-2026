# Image Director — 七模块 AI 生图导演（Agent Skill）

> 主体设定 + 场景动作 + 视觉风格 + 构图镜头 + 光影色彩 + 材质细节 + 负面约束
> 别再把 AI 绘图当抽盲盒：模型负责生成，你负责审美和设计。

## 这是什么

一个成品级 Agent Skill：把"脑子里有画面但描述不清"拆成**七个必答模块**，并用**双层架构**解决"绑定 GPT 还是做通用"的纠结——

```
语义层（模型无关）：7 个模块 = 画面必须交代清楚的 7 类信息
方言层（按模型切换）：同一份画面圣经，翻译成目标模型最听得懂的提示词
```

- **GPT Image 系**吃自然语言长描述（按它写效果最棒的原因），语义层原文直投
- **Midjourney** 吃短语 + `--ar`/`--no`/`--stylize` 参数
- **SD / FLUX** 吃质量词标签堆叠 + 独立负面提示词框 + 权重语法
- **国产对话生图**（即梦/可灵/豆包类）吃 100–300 字中文自然语言

一份画面圣经通吃所有模型，换模型只重跑翻译层，不重写描述。

## 七模块

| # | 模块 | 一句话 |
|---|------|--------|
| 1 | 主体设定 | 写事实不写评价（年龄/脸型/发型/服装/特征锚点） |
| 2 | 场景与动作 | 有动作才有故事感，目光必须给落点，手必须有事做 |
| 3 | 视觉风格 | 不写"高级感"，写到底是哪一种高级感（风格速查表 8 种） |
| 4 | 构图与镜头 | 画幅/景别/机位/布局四件事写满，布局给百分比 |
| 5 | 光影与色彩 | 方向+质地+层次；底色+独立色+肤色，禁止整图偏色 |
| 6 | 材质与细节 | 皮肤/服装/头发/环境四个细节位，比画质形容词管用 |
| 7 | 负面约束 | 通用 7 条 + 定制 2–3 条；改图必加不变量声明 |

## 解决什么问题

| 症状 | 根因（对应模块） |
|------|----------------|
| 平均脸、每次生成不一样 | 01 写了评价词没写事实、缺特征锚点 |
| 人物站直看镜头、一眼假 | 02 缺动作与目光落点 |
| 说好高级感结果四不像 | 03 没指明是哪一种高级感 |
| 构图永远居中大头 | 04 四要素没写满 |
| 廉价滤镜感、皮肤塑料 | 05 整图偏色 + 06 细节位缺失 |
| 手指异常、改图崩全图 | 02 手部无事做 + 07 缺不变量声明 |
| 提示词很长但没效果 | 08 用错方言（长度/位置/语法不匹配） |

## 使用

直接说人话触发：

- "画一张午后咖啡馆的女生，9:16 当小红书封面"
- "这张图改一下背景，人别动"
- "出图老是手指畸形，帮我修提示词"
- "同一段描述帮我转成 Midjourney 版"

执行顺序：填画面圣经（7 模块）→ 按目标模型查方言表翻译 → 投放 → 症状表单点修复 → 命中锁基线。
